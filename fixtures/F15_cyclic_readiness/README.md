# F15: cyclic readiness fixed point

This exact finite fixture exercises readiness propagation on a dependency
cycle. Mathematical verdicts are carried unchanged. Readiness is represented
as a product of three independently ordered axes, and the source claim omits
the inapplicable `FORMAL` axis rather than assigning it an artificial value.

The `MODEL` and `DECISION` nodes form a cycle. The monotone cap from the
decision back to the model lowers identity authority; that change propagates
around the cycle until the greatest feasible fixed point is reached. The
retained receipt is generated by `tools/bsc_claim_readiness.py`. The fixture
cross-checker imports that implementation, then adds exhaustive enumeration of
every assignment below the input and verifies that the retained result is
feasible and componentwise above every other feasible assignment. This is a
strong same-implementation cross-check, not an independent verifier.

The generator rejects graphs above fixed ceilings: 1,000,000 input bytes,
JSON depth 32, 50,000 JSON items, 32 axes, 64 levels per axis, 512 nodes, 4,096
edges, 4,096 applicable coordinates, 100,000 descent steps, and 10,000,000
fixed-point readiness operations. It also bounds identifiers and integers,
rejects Unicode surrogates, and emits typed failures on standard error without
echoing local paths.

The string `independently-checked` is only one ordinal level inside the toy
input. It does not classify this fixture's own verification route.

The machine-readable [`provenance.json`](provenance.json) records the input,
generator, shared-model cross-check, arithmetic class, and authority boundary.
It is source-bound by the selected-claim package; it is not evidence of an
independent implementation.

Run from the repository root:

```bash
python3 fixtures/F15_cyclic_readiness/check_fixture.py
```

This fixture establishes only the declared finite graph result. It does not
certify the readiness of any external scientific claim, and it does not turn
readiness into a scalar score. Receipt hashes bind exact bytes but do not
provide confidentiality for private or guessable material.
