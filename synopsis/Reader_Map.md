# Reader map

Use the row nearest your field. This map uses section and fixture identifiers
rather than printed page numbers, which move as development material is added.

The released baseline is v1.2.0. The simulation-evidence row identifies
material in `framework/Simulation_Evidence_Profile.md` and executable Fixture
F10; it does not alter the v1.1.0 zeta–DQPT verdicts or claim execution for any
external simulator. The current `1.3.0-dev` tree adds the operational-channel
row; it does not alter the immutable release or close BSC-QOP-03.
